# 更新日志

## 1.0.5 — 2026-11-17

- `compactEvents` 现在在重叠流之间保留消息顺序和快照边界，修复了并行工具调用被交换、增量被流中途快照覆盖的问题。
- 重叠流之间到达的事件现在保持到达顺序，避免 `STEP_STARTED`/`STEP_FINISHED` 序列被 `verifyEvents` 拒绝。
- 推理消息增量（`REASONING_MESSAGE_CONTENT`）现在像文本消息一样被压缩，大幅减小存储的历史大小。
- 大型重放线程通过 `MessageLookup` 索引按消息和工具调用 id 查找，取代全列表扫描，应用速度大幅提升。
- `AbstractAgent.clone()` 现在复制 `resolvingPeerCeiling`，克隆对象保留所有自有字段。
- 强制校验现在拒绝缺失、非字符串或继承的联合判别符。

### 破坏性变更

- 事件强制校验拒绝此前被接受的缺失、非字符串或继承的联合判别符；请验证发出的事件符合规范。
- `compactEvents` 的输出顺序和推理增量压缩行为已改变；请重新验证任何依赖先前事件顺序或原始推理增量的代码。

## 1.0.4 — 2026-11-05

- 不再为每个事件深克隆整个线程；每次更新只复制变更的消息，消除了长线程上的二次方开销。
- 发出的消息为只读；发出的状态和活动内容会被复制，消费者编辑不再泄漏到 reducer 的工作副本或后续事件中。
- `threadId` 现在是延迟生成的访问器，允许在 Cloudflare Worker 全局作用域构造 agent 而不崩溃。
- 重做了工具结果/调用配对：在运行输入、快照合并以及复用调用 id、human-in-the-loop 和推理消息场景下重新配对结果与调用。
- 工具结果现在放在推理之前而非之后，修复了 LangGraph/Mastra 的处理。
- 新增每事件条目预算，限制 schema 强制校验的工作量，防止无界容器大小（CVE-2023-54404 缓解措施）。
- `zod` 现在是 peer 依赖（`^3.25.18 || ^4.0.0`），不再是直接依赖。
- 修复了异步 `onNewMessage` 和 `onNewToolCall` Hook 上被丢弃的 await。
- 避免序列化被丢弃的未知事件。
- Mastra：`clone()` 现在将 `use()` 中间件带到克隆的 agent 上。

### 破坏性变更

- `threadId` 现在是 `AbstractAgent` 上的访问器；将 `threadId` 声明或覆盖为字段的子类会失败（TS2610）。请在构造函数中赋值。
- `threadId` 不再是自有属性；在读取之前，它不出现在 `Object.keys`、展开和 `JSON.stringify` 中。
- `zod` 从直接依赖改为必需的 peer 依赖（`^3.25.18 || ^4.0.0`）；应用必须安装兼容的 zod。
- `AbstractAgent.middlewares` 现在是 protected。
- 工具结果排序和重新配对行为已改变；请重新验证任何依赖先前消息顺序的代码。

## 1.0.2 — 2026-10-05

- 客户端现在接受更多以 `null` 发送的可选字段并将其视为缺失，每次运行每个字段警告一次。此前这些会导致运行失败。
- agent 出错前收到的事件（包括 `RUN_ERROR`）现在会到达 `onEvent` 和 `onRunErrorEvent`，不再被丢弃。
- HTTP 流清理失败不再掩盖原始流错误。

### 破坏性变更

无。

## 1.0.1 — 2026-09-29

- 修复了 `connectAgent()` 在重新连接到有待处理中断的线程时失败的问题；连接现在读取线程历史，无需恢复答案。
- 恢复/中断检查现在仅适用于提交答案的输入，允许重新加载以恢复被中断的线程。

### 破坏性变更

无。

## 1.0.0 — 2026-09-17

- 新增 1.0 强制校验流水线，在中间件之后运行：按 Schema 剥离并校验。
- 新增 protobuf 线格式支持和兼容中间件。
- 快照元数据现在允许生产者只声明其权威的活动类型，因此 A2UI 中间件等投影器不会删除其他生产者拥有的活动。
- MESSAGES_SNAPSHOT 现在按快照顺序应用，而非将未见消息追加到末尾，修复了重新键控的消息顺序。
- 修复了不重排历史的作用域活动删除，并保留完整的活动快照权威。
- 限制重放缓冲区，并对 SSE 和 protobuf 分帧缓冲区设上限，避免保留整个响应。
- 流失败时停止上游读取并取消 HTTP reader，不再仅在完成时执行。
- 推理事件不再覆盖共享同一 id 的活动消息。
- 每次运行现在拥有自己的被阻止工具调用 ID 集合，卡住的运行的过滤事件不再泄漏。
- FilterToolCallsMiddleware 在运行边界清除被阻止的工具调用 ID。
- 在旧版 convert 和 a2a 中间件中保护 JSON.parse 并暴露流错误。

### 破坏性变更

- 线协议版本现在是生成的 PROTOCOL_VERSION（"1.0"）。
- 强制校验流水线现在在中间件之后运行，并按 Schema 剥离/校验，改变了通过的事件。
- MESSAGES_SNAPSHOT 的顺序和活动所有权语义已改变；请重新验证快照处理。
- 分帧缓冲区现在设上限；超大无界流将报错而非持续增长。
