# 更新日志

## 1.0.0 — 2026-09-17

- 将草案 Schema 冻结为 1.0；`PROTOCOL_VERSION` 现在为 "1.0"，Schema 的 `$id` 移至 `/spec/1.0/schema.json`。
- `ag_ui.core` 重新导出生成的 1.0 模型，0.x 名称保留为别名。
- 新增生成模型：内容部分、工具结果部分、能力、运行结果、含缓存写入的 token 用量、文件来源。
- 序列化时省略可选的 null 字段；载荷中的 null 保留。
- 唯一的线上协议版本现在为生成的 `PROTOCOL_VERSION`。
- 在 PyPI 上发布的包元数据中新增稳定的 Changelog 项目 URL。

### 破坏性变更

- 线上协议版本变更为 "1.0"；比较版本的消费方必须重新验证。
- 模型名称改为 1.0 名称（0.x 名称保留为别名）；请核对导入。
- 移除了冗余的 `MetadataMixin` 导出。
- 序列化现在省略可选的 null，发出的载荷随之改变。
