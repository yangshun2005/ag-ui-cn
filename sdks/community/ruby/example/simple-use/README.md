# AG-UI Ruby 示例：简单用法

本示例演示如何使用 AG-UI Ruby SDK 创建并编码事件。

## 前置条件

- **Ruby**：3.0 或更高版本

 ```bash
  # 检查 Ruby 版本
  ruby --version
  ```

- **Bundle**：2.5.14 或更高版本

```bash
# 检查 Bundle 版本
bundle --version
```

## 安装

### 1. 克隆仓库

```bash
# 克隆 AG-UI 仓库
git clone https://github.com/ag-ui-protocol/ag-ui.git
cd ag-ui
```

### 2. 安装依赖

```bash
# 进入 Ruby 示例目录
cd sdks/community/ruby/example/simple-use

# 安装依赖
bundle install
```

## 运行示例

```bash
bundle exec ruby main.rb
```
